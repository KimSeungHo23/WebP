https://kimseungho23.github.io/WebP/0930/report/김승호/

"개인 소비 관리 대시보드 웹사이트를 만들어줘. 다음 3가지 핵심 기능이 반드시 포함되어야 해.
1. 오늘 쓴 돈 기록: 지출 금액, 카테고리(식비, 쇼핑, 고정비 등), 간단한 메모를 입력하고 하단 리스트에 추가할 수 있게 해줘.
2. 월별 지출 통계: 이번 달 누적 총 지출액과 카테고리별 지출 금액을 한눈에 볼 수 있는 통계 카드와 시각적 바(Bar) 그래프를 보여줘.
3. 예산 초과 알림: 사용자가 설정한 월 목표 예산(예: 300,000원)을 입력할 수 있게 하고, 지출이 예산을 초과하면 상단에 눈에 띄는 빨간색 경고 배너와 메시지가 뜨게 해줘.
전체적인 UI 디자인은 모던하고 깔끔한 대시보드 형태로 구성해 줘."

"Supabase 데이터베이스를 연결해서 오늘 쓴 돈과 통계 데이터가 새로고침 후에도 유지되게 해줘"
